# 下载
提供两种 Windows 发行形态：安装版与便携版。

---

::: info 下载地址

| 渠道 | 说明            |
|------|---------------|
| **[GitHub Releases](https://github.com/Empty-57/ZeroBit-Player/releases)** | 推荐；版本与安装包最全   |
| **[Gitee](https://gitee.com/empty-57/ZeroBit-Player/releases)** | 访问慢时用；版本更新较滞后 |

进入最新版本后，选择：

- 安装版：`zerobit_player_setup.exe`
- 便携版：`zerobit_player.zip`

`Source code` 是源码归档，不是可直接运行的程序。
:::

## 系统要求

- **Windows 10 / 11**（官方支持；Windows 7 / 8 不可用）
- 建议 4GB 及以上内存
- 约 100MB 可用磁盘空间

## 安装版

1. 下载 `zerobit_player_setup.exe` 并运行
2. 按向导完成安装
3. 可选创建桌面快捷方式
4. 启动

## 便携版

1. 下载发布包并完整解压到任意位置
2. 运行 `zerobit_player.exe`

## 数据位置
所有用户数据和音频数据均保存在 `C:\Users\<用户名>\Documents\zerobit_config` 

::: info SmartScreen
首次运行时 Windows 可能弹出 SmartScreen 提示，点击「更多信息」→「仍要运行」即可。
:::
