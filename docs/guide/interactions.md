# 交互与手势

一些基本操作。

### 歌词

| 操作    | 效果                           |
|-------|------------------------------|
| 点某一行  | 跳到这句开始唱的位置                   |
| 自己滑歌词 | 大约 **3 秒**内不会强行滚回当前句，重新滑重新计时 |
| 对齐    | 左 → 中 → 右循环                  |
| 注音    | 是否显示注音                       |
| 翻译    | 是否显示翻译                       |

### 右键菜单
- 调整字号 / 字重
- 添加到自定义歌单
- 跳转到对应艺术家 / 专辑页面

## 底部迷你播放条

主界面最底下那一条：

- 点击 → 进入播放页  
- 鼠标放上去才出现 上一首 / 下一首 / 播放模式 / 音量 按钮，停一会儿会再藏起来  

## 音量条

- 点音量按钮会弹出滑条，拖动可调音量
- 鼠标放在音量按钮上时可用鼠标滚轮快速调音量

## 音乐 / 艺术家 / 专辑 / 歌单 / 文件夹

| 操作     | 效果        |
|--------|-----------|
| 点击多选   | 进入多选      |
| 右键     | 弹出功能菜单    |
| 回到顶部 | 滚动到列表顶部   |
| 定位     | 滚动到当前播放音乐 |
