# 歌词

## 本地歌词怎么放

把歌词文件和歌曲放在**同一目录**，文件名尽量一致，例如：

`歌名.flac` → `歌名.lrc` / `歌名.qrc` / `歌名.yrc` / `歌名.krc`

同目录有多份歌词时，优先顺序：

`.qrc` > `.krc` > `.yrc` > `.lrc`

找不到本地歌词时会尝试读取内嵌歌词，自动处理常见中文/日文编码，部分加密格式会自动处理。

## 哪些是逐字、哪些是逐行

| 格式                                    | 常见效果 |
|---------------------------------------|------|
| 普通 LRC                                | 逐行特效 |
| 逐字 LRC、增强 LRC、YRC / QRC / KRC | 逐字特效 |

**能不能逐字，取决于歌词文件本身**，没有「强制变成逐字」的开关。

## 在线歌词

「设置 → 常规 -> API源」里选在线源。

若开启了 `自动保存获取的歌词` 则会把获取到的歌词保存在歌曲同目录下。

歌词不准确时：

1. 换一个在线源  
2. 检查歌曲的歌名、艺人标签对不对  
3. 播放页「更多 → 歌词来源」里手动搜索，或指定某个本地文件  

不是每首歌、每个源都有翻译或注音；源里没有时，软件不会自己编。

## 原文、翻译、注音

有数据时可以一起显示，在「播放页右下角 - 翻译 - 注音」开关。

时间轴乱、翻译对不齐时，优先怀疑**外挂 / 内嵌歌词文件质量**；可改用在线搜一条，或换更好的本地文件。详见 [FAQ](/guide/faq#原文-翻译-注音对得不准、对不齐)。

## 怎么调显示和动效

### 播放页
- 右键菜单可设置： 字号、粗细、左中右对齐
- **翻译、注音**显示开关（有数据才能开；原文一般始终显示）

### 设置 → 歌词
- 非当前行是否模糊
- 是否启用弹簧滚动
- 是否启用动态背景
- 调整字体字号

### 其它小体验

- 歌词列表上下边缘会略微变淡  
- **用手滑了一下歌词**后，大约 3 秒内不会强行滚回当前句，方便你自己翻

独立窗口见 [桌面歌词](/guide/desktop-lyric)。设置总表见 [外观与设置](/guide/settings)。

## 没有歌词时

1. 文件是否和歌曲同目录、同名  
2. 扩展名是否支持  
3. 用记事本另存为 UTF-8 再试  
4. 更换API源
5. 仍不对：播放页「网络歌词」手动搜或自定义内嵌歌词
