# 快捷键

下面这些是**可自定义**的。

| 按键（默认值）    | 作用        |
|------------|-----------|
| `Space`    | 播放 / 暂停   |
| `←`      | 上一首       |
| `→`      | 下一首       |
| `F1`      | 全屏 / 退出全屏 |

## 没反应时先看这几条

1. 是不是正在搜索框或其它输入框里打字？（这时播放快捷键会暂时关掉）
2. 别的软件有没有占用同样的全局热键？  
3. 耳机 / 键盘上的「媒体键」走系统媒体控件，和上表是两套，一般可以一起用  

系统总音量：点播放页音量，用下面那一条。更多交互见 [交互与手势](/guide/interactions)。
