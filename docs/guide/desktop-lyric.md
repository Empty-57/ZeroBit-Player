# 桌面歌词

单独一个小窗口，全屏玩游戏、看视频时也能瞟歌词。在**播放页**打开，样式在「设置 → 桌面歌词」里调。

桌面歌词窗口会隔几秒就请求置顶，一般不会被其他软件覆盖。

## 能调整什么

- 已播放 / 未播放颜色
- 字号 / 字重 / 对齐方式 / 透明度 / 字体
- 文字颜色是否跟随主题色
- 文字边框 / 边框颜色
- 横排 / 竖排显示
- 是否忽略鼠标事件
- 歌词换行特效

窗口默认浮在其它窗口上面、背景透明。

## 常见情况

**看不到窗口**  
是否被其他软件覆盖；任务栏有没有歌词进程；程序目录内是否少了的 `desktop_lyrics` 文件夹。

**和主窗口对不上**  
先看主窗口这首歌歌词是否正常，再切一首试。主程序退出后，桌面歌词一般也会一起关。

**颜色太淡**  
开描边，或自定义已播放 / 未播放颜色。
