# 简介
ZeroBit Player 是一款 `Material` 风格，简洁的多功能本地音频播放器，基于 `flutter` + `rust` + `bass` 开发。

## 它能做什么

| 方向 | 能力                                         |
|------|--------------------------------------------|
| 音乐库 | 按歌曲 / 艺术家 / 专辑 / 文件夹 / 歌单浏览，全局搜索           |
| 播放 | 顺序 / 循环 / 单曲，随机，会话恢复，淡入淡出                  |
| 音频 | 10 段 EQ、调速、ReplayGain、WASAPI 独占            |
| 歌词 | 本地外挂 + 内嵌 + 在线（QQ / 网易 / 酷狗），原文 / 翻译 / 罗马音 |
| 界面 | 黑白配色、Material You、特效歌词、桌面歌词                |
| 系统 | SMTC、快捷键、单实例、更新检查、持久化存储                    |
