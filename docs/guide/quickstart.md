# 快速上手

从导入曲库到开始播放，大约几分钟。

::: info 音频数据不会被更改
程序只读取你选择的文件夹内的音频和歌词文件，只在应用数据目录保存索引和设置（ `C:\Users\<用户名>\Documents\zerobit_config` ），不会复制、移动或删除原音乐文件。
:::

## 导入音乐
1. 设置 -> 常规 -> 歌曲文件夹 - 管理
2. 点击添加后 -> 确定
3. 等待扫描完成
4. 在「音乐 / 艺术家 / 专辑 / 文件夹 / 歌单」中点任意歌曲即可

## 侧栏导航

| 入口 | 用途                  |
|------|---------------------|
| 音乐 | 全部歌曲列表              |
| 艺术家 / 专辑 | 按艺术家 / 专辑分组类的视图     |
| 文件夹 | 按目录结构分类的歌曲列表        |
| 歌单 | 自建的歌曲列表             |
| 设置 | 主题、个性化、歌词、桌面歌词、快捷键等 |

## 播放页基础

- 默认局内快捷键：`Space` 播放 / 暂停，`F1` 最大化或还原窗口， `←` 上一首， `→` 下一首
- 封面会取色，界面主题和背景会跟着变
- 更多见 [播放与音频](/guide/player)、[歌词](/guide/lyrics)、[交互与手势](/guide/interactions)

::: tip 关于歌词
优先读取本地歌词，本地没有歌词的时候会读取内嵌歌词，如果都没有则会从线上获取歌词。
:::

## 新增音乐
- 软件每次启动会自动同步目录中音频的变动，也可以进入 `歌曲文件夹 - 管理` 点击确定手动同步
- 从曲库移除文件夹只会取消索引，不会删除磁盘上的音乐
