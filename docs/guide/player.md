# 播放与音频

## 播放控制
| 能力 | 说明 |
|------|------|
| 播放模式 | 顺序 / 列表循环 / 单曲循环 |
| 会话恢复 | 下次打开尽量回到上次的歌和播放列表 |
| 淡入淡出 | 普通（共享）模式下切歌会有短暂过渡；独占模式是直接切 |
| 系统媒体控件 | 任务栏 / 键盘媒体键：播放、暂停、上下曲 |

## 调速
在播放页打开调速面板：
- 可调区间 0.5 - 2.0
- 独占和共享模式下均有效

## 均衡器
播放页打开 EQ：

- 10 个频段（80hz - 16khz），每段 ±12 dB
- 可使用内置的数个风格的预设
- 独占模式下均有效

## 输出模式
| 模式 | 适合         | 注意                       |
|------|------------|--------------------------|
| 共享（默认） | 日常听歌       | 无                        |
| WASAPI 独占 | 想输出更高质量的音频 | 直接访问音频设备，其他软件没声音，失败会提示并退回共享 |

独占打不开时：先关闭其他占用了声卡或开启了独占模式的程序。

## 音量与 ReplayGain
鼠标放在音量图标上可使用鼠标滚轮或者手动拖动来调整软件内音量，不影响系统音量。

**ReplayGain**（设置 → 常规）：如果歌曲标签里带有ReplayGain信息，可自动把音量偏大/偏小的歌拉齐一点，标签里没有则无效果，可用foobar2000批量给音频添加此标签。

## 播放页

- 可在 设置 -> 歌词 里面调整歌词外观
- 若开启了动态主题色，主题色会随着封面变化

背景是封面取色后的流动渐变，随当前歌曲变化。
