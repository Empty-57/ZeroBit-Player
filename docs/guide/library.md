# 音乐库

## 添加与排除
- 从 设置 -> 常规 -> 歌曲文件夹 - 管理 管理音乐库
- 扫描会递归子目录，索引写入本地 `.hive` 文件
- 从曲库移除目录不会删除本地音乐文件

## 更新曲库
- 已添加目录中有新增、修改或删除的文件时，在 `歌曲文件夹 - 管理` 点击确定，即可手动刷新
- 重启软件会自动同步音乐库的变动
- 修改音乐标签后，会自动同步数据的修改

## 浏览方式
| 视图 | 说明                       |
|------|--------------------------|
| 音乐 | 全部曲目                     |
| 艺术家 | 按艺术家聚合的视图                |
| 专辑 | 按专辑聚合                    |
| 文件夹 | 按实际目录                    |
| 歌单 | 用户自建列表                   |

支持列表 / 表格视图与排序。

## 列表操作
右键音频条目：
- 加入播放队列 / 下一首播放
- 加入自建歌单
- 查看和编辑元数据（码率、采样率、标签等）
- 编辑内嵌歌词
- 跳转到对应专辑页
- 跳转到对应艺术家页
- 从歌单移除（歌单页）

## 搜索
全局搜索可覆盖歌曲、艺术家、专辑。适合大库快速定位。

## 支持的音频格式
常见可扫描格式包括：

`aac`、 `ape`、 `aiff`、 `aif`、 `flac`、 `mp3`、 `mp4`、 `m4a`、 `m4b`、 `m4p`、 `m4v`、 `mpc`、 `opus`、 `ogg`、 `oga`、 `spx`、 `wav`、 `wv`、 `dff`、 `dsf`

实际播放依赖内置音频引擎与格式插件。若某格式能扫描但无法播放，优先检查文件是否损坏、是否为不支持的编码变体。

## 封面与标签
- 标签与封面由后端读取
- 会根据已选择的API源自动为没有封面数据的音频匹配封面
- 封面会缓存，减少重复解码
- 大库首次建索引会更吃磁盘与时间，属正常现象

## 数据位置与备份
位于 `C:\Users\<用户名>\Documents\zerobit_config`

设置、曲库、歌单、都在这目录里。从曲库「移除文件夹」不会删除磁盘上的音乐文件。
