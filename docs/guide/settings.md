# 外观与设置

## 常规

| 项                  | 备注                                |
|--------------------|-----------------------------------|
| 歌曲文件夹              | 管理音乐库                             |
| API源               | 管理封面 / 歌词 的获取途径                   |
| 自动保存获取的歌词          | 无                                 |
| 自动从API获取歌词         | 找不到本地或者内嵌歌词的时候自动从API获取歌词          |
| 启用独占模式             | 无                                 |
| 启用音量平衡（ReplayGain） | 无                                 |
| 使用任务栏缩略图工具栏控制播放    | 若开启，鼠标放在软件的任务栏图标时，TaskBar上会出现控制按钮 |
| 关闭窗口后在后台运行         | 若开启，点击退出时软件会在后台运行                 |

切换深色 / 浅色模式的按钮位于顶部工具栏。

## 外观

| 项        | 备注                  |
|----------|---------------------|
| 主题色      | 可自定义整个软件的配色         |
| 动态主题色    | 若开启，软件配色会随着歌曲封面颜色改变 |
| 字体       | 更换软件字体              |
| 更改背景     | 更改软件的背景图像           |
| 背景图片不透明度 | 无                   |
| 背景图片模糊值  | 无                   |

## 歌词

| 项              | 备注                                 |
|----------------|------------------------------------|
| 字号 / 字重        | 更改播放页歌词的字号 / 字重                    |
| 使用动态背景         | 若开启则使用动态背景否则使用静态背景                 |
| 歌词行模糊          | 若开启，非当前行歌词会被应用模糊效果                 |
| 使用弹性滚动         | 若开启，则歌词换行的时候会应用弹性效果                |

详见 [歌词](/guide/lyrics)。

## 桌面歌词

| 项           | 备注                               |
|-------------|----------------------------------|
| 开启桌面歌词      | 无                                |
| 字号 / 字重     | 无                                |
| 不透明度        | 更改桌面歌词不透明度                       |
| 已播放颜色跟随主色   | 若开启，已播放的颜色会跟随主色，未播放颜色为白色         |
| 已播放 / 未播放颜色 | 自定义 已播放 / 未播放 颜色，若上一设置项启用，改动仍能生效 |

详见 [桌面歌词](/guide/desktop-lyric)。

## 快捷键

|---------|---------------|

| 下一首     | -             |

## 数据在哪、怎么备份

位于 `C:\Users\<用户名>\Documents\zerobit_config` 直接复制备份即可。
