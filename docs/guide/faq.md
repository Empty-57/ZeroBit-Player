# 常见问题

按场景查找。功能怎么用见各指南页。

## 安装与启动

### 装安装版还是便携版？

都可以，详见 [安装](/guide/install)。

### GitHub 很慢，能用 Gitee 吗？

可以。[Gitee 仓库](https://gitee.com/Empty-57/ZeroBit-Player/releases) 是镜像，方便国内访问。

注意：**Gitee 上的自动同步经常很慢，约等于没有**，Release / 代码可能长时间落后于 GitHub。若两边版本号或说明不一致，以 **GitHub Releases** 和本站 [更新日志](/guide/changelog) 为准。

### 被 SmartScreen 拦住？

点「更多信息」→「仍要运行」。软件尚未签名时很常见。

### 杀毒软件报警？

多数是误报。把程序所在文件夹加入白名单。可对照 GitHub 源码和发布页。

### 便携版解压后打不开？

1. 系统是否为 **Windows 10 或 11**（Win7 / 8 不支持，见下一条）  
2. **完整解压**，不要在压缩包里直接双击  
3. 确认同目录有一堆 dll，以及 `BASSDLL`、`desktop_lyrics` 文件夹（不要只拷一个 exe）  
4. 安装最新 Visual C++ 运行库  
5. 文件夹要能写入，并看是否被杀软隔离  

### Windows 7 / 8 能用吗？

**不能作为支持目标。** 官方只面向 Windows 10 / 11。底层用的 Flutter 桌面端也不支持 Win7/8，即使勉强拷文件过去，通常也跑不起来或不稳定。请升级系统，或换一台 Win10+ 的电脑。

### 启动很慢？

第一次或歌特别多时，要读曲库和封面，等扫描/加载走完。若一直失败见下面「曲库读不出来」。

### 为什么不能开两个窗口？

设计为单实例：再开一次会跳到已打开的窗口。

### 怎么更新又不丢设置？

别手动删除 `C:\Users\<用户名>\Documents\zerobit_config` ，设置和曲库信息就会被读取。
- 安装版：先退出 → 装新版覆盖
- 便携版：解压到新文件夹 → 把旧程序文件夹删掉


### 怎么卸载？

- **安装版**：双击程序目录下 `unins000.exe`
- **便携版**：退出后删整个文件夹。

### 换电脑 / 配置好像丢了？

拷贝整个 `C:\Users\<用户名>\Documents\zerobit_config` 文件夹，复制到新电脑相同位置。

## 曲库与列表

### 扫描特别慢？

第一次建库要读每首歌的标签和封面，歌越多越久，属正常。以后再开会快很多。

### 有些歌扫不进来？

- 格式是否支持（见 [音乐库](/guide/library)）
- 文件是否损坏或没权限  

可重新添加上层文件夹再扫一次。

### 新拷进文件夹的歌列表里没有？

到「设置 -> 常规 - 歌曲文件夹」点**确定**。软件**不会**一直监视硬盘变化；或者**重启**软件也行。

### 磁盘上删了歌，列表里还在？

同上。

### 封面、歌名、艺人对不上？

信息来自文件自己的标签。用标签工具改好后，回到本软件**刷新曲库（就是上面说的方法）**。点进编辑元数据可看元数据等，部分信息也可改。

### 曲库读不出来 / 初始化失败？

到「设置 → 关于 → 反馈」报告问题。常见原因：数据目录不能写、磁盘满、库文件坏了。
可先备份整个数据文件夹，再尝试删掉其中的曲库文件后重新扫描。拿不准时带日志来问。

### 同一个艺人变成好几个？

默认的艺术家分隔符是 `/` （暂不可改），标签写成「张三/李四」会拆成两人。

### 搜索搜不到？

搜索靠已扫描到的歌名、艺人、专辑。标签空或写错会对不上；改标签后刷新。

### 多选不好用？

在列表里点击**多选模式**进入多选。

## 歌单

### 歌单和「播放队列」有什么区别？

| | 歌单        | 当前播放列表              |
|--|-----------|---------------------|
| 是什么 | 你自定义的音频列表 | 这一次排队要听的顺序          |
| 在哪 | 侧栏「歌单」    | 侧栏「播放队列」播放页下方「播放列表」 |
| 关掉软件 | 还在        | 下次启动会使用上一次的播放队列     |

从歌单删除 ≠ 删除文件。

### 加不进歌单？

同一首不会重复加。歌单名不能重复；磁盘要能写入。

### 从歌单里移除会删文件吗？

不会，只是不再出现在这个歌单里。

## 播放与声音

### 点了没声 / 播放保错？

- 文件是否被移动、改名或损坏  
- 是否缺 dll
- 试着关掉独占，用默认共享模式
- 其他疑难杂症

### 开不了「独占」？

1. 别的软件是否占着声卡
2. 仍失败会退回共享，可再试一次
3. 格式本身不支持

### 独占和 EQ 能一起开吗？

可以

### 切歌几乎听不到淡入淡出？

只有共享模式有很短的过渡；独占是硬切。过渡本身很短，听感可能不明显。

### 有的歌特别响、有的特别轻？

开 **ReplayGain**（设置 → 常规；歌曲标签里要有ReplayGain信息）。

### ReplayGain 没感觉？

很多文件标签里没有ReplayGain信息，这时开了也不会变。可用标签工具（推荐foobar2000）写入后再试。

### 键盘媒体键没反应？

媒体键走系统媒体控件。关掉其它正在播的软件再试；确认 Windows 没有禁用媒体控件。

## 歌词加载

### 有歌词文件却不显示？

1. 是否和歌曲**同一目录**、文件名必须相同  
2. 扩展名是否支持（`.yrc` / `.qrc` / `.krc` / `.lrc`）  
3. 用记事本另存为 UTF-8 再试

### 为什么不能一个字一个字亮？

看歌词是不是逐字做的。普通 LRC 常常只有「一行一个时间」。要逐字效果需 YRC、QRC、KRC、增强 LRC、逐字 LRC 。

### 在线歌词对上了错歌？

换源、改准歌名艺人后再搜；或在「网络歌词」里手动挑一条。

### 翻译 / 注音开关没用？

说明**当前这首**没有翻译或注音数据。换一首或换源后再看。

### 为什么这首歌的在线歌词没有注音？

多半是**这个源本身就没提供注音**（有的歌只有原文，有的带翻译但不带注音）。不是开关坏了。可以：

- 换一个在线源再搜一次  
- 到「网络歌词」里换一条结果试试  

都没有的话，就是这首在这些源上没有注音，软件无法凭空生成。

### 支持日语假名注音吗？

暂不支持。

### 原文 / 翻译 / 注音对得不准、对不齐？

常见是**本地外挂或内嵌歌词**本身时间轴、分行、翻译对得就不好，不是显示开关的问题。可以：

1. 播放页「网络歌词」里搜一条更干净的  
2. 仍用本地时：换一份质量更好的歌词文件，或检查是否点错了同名但内容很差的文件  

在线也偶尔会配错歌，那时换源或手动挑一条即可。

## 歌词动效（缩放、发光、上抬…）

### 什么情况下会对歌词使用「辉光缩放」？

1. 当前歌词是逐字歌词  
2. 某个词的持续时间大于1.5秒
3. 动画区间为 [1.5s - 3.0s] 即当前词持续时间大于1.5s时才会有动画，持续时间大于3s时动画值最大值（缩放和辉光等级）达到最大

### 上抬动效不明显？

目前上抬幅度为固定值，暂不可自定义。

### 模糊开关在哪？

在 「设置 -> 歌词 - 歌词行模糊」。

### 自己滑了歌词，歌词列表就不滚动了？

大约 **3 秒**内让你自己翻看，之后会回到当前行，若**3 秒**内重新滚动则会重新计时。

### 开头没有「前奏」动画？/ 中间没有「间奏」动画？

这是**两样东西**：

| | 开头前奏                       | 中间间奏            |
|--|----------------------------|-----------------|
| 出现时机 | 第一句真正开唱之前，前面空了比较久          | **两句歌词之间**空了比较久 |
| 常见阈值 | 大约空 **4 秒以上**              | 大约空 **4 秒以上**   |

目前仅逐字歌词支持间奏和前奏动画。

所以：**歌一开头就有人声、几乎没有静音**，本来就不会有前奏动画；**句与句贴得很紧**，也不会有中间间奏。

## 桌面歌词

### 窗口看不到？

- 是否已打开桌面歌词  
- 是否被其他软件全屏盖住  
- 是否缺少 `desktop_lyrics` 文件夹  
- 杀软是否拦了子程序  

### 和主窗口歌词对不上？

先看主窗口这首是否正常，再切一首。主程序退出后，桌面歌词一般也会关。

### 颜色看不清？

开「边框」并设置「边框颜色」；或关掉「跟随主题色」，自己选已播放 / 未播放颜色。

## 界面

### 主题色不跟封面？

设置 → 外观：开启动态主题色，且这首要有封面。没封面或获取的颜色不太合适时用默认颜色。

### 播放页底栏老消失？

为了少挡歌词：底栏、次要按钮往往要**鼠标移过去**才完整显示。

### 换了字体没变化？

字体可能没安装成功或者字体不可用。

## 快捷键与其它

### 快捷键完全没反应？

1. 是不是在搜索框里打字？（这时会暂时关掉快捷键）   
2. 其它软件是否占用了同样按键？  
3. 自定义快捷键仅在软件内生效，系统媒体快捷键全局生效（前提是没有其他软件抢一样的快捷键）

快捷键可自定义，见 [快捷键](/guide/hotkeys)。

### 检查更新失败？

- 应用查 **GitHub** 上的版本
- 网络链接不了 GitHub 时可能检查失败

可到「设置 -> 关于」里使用手动检查。

### 怎么反馈问题？

先在本页搜索现象并按相关条目排查。常见问题没有答案、但还不能确认是程序问题时，可以先到 [Discussions](https://github.com/Empty-57/ZeroBit-Player/discussions/categories/general) 交流；已经能够复现的异常，再使用对应的 [Issue 模板](https://github.com/Empty-57/ZeroBit-Player/issues/new/choose) 提交。

在「设置 → 反馈」中跳转到浏览器反馈问题，尽量带上软件目录下 `logs` 内的日志。

提交前可以按下面的顺序自查：

1. **先确认问题类型**：已经能稳定说明异常行为和复现条件，使用 Bug 模板；还在确认原因或只是询问用法，先到 [Discussions](https://github.com/Empty-57/ZeroBit-Player/discussions/categories/general)；功能请求、改进建议和文档问题分别使用对应模板。
2. **确认版本和环境**：填写软件版本、Windows 版本、安装方式、复现频率和最后正常版本；自行构建或其他来源的版本还要写提交版本和本地改动。
3. **确认不是文件或设置问题**：音频、标签和歌词问题先检查原文件能否读取、标签是否正确，并用一个已确认有效的文件做对照；只影响单个文件时，请附原文件或可复现样本。
4. **准备对应材料**：播放问题写输出设备和音频格式；性能或崩溃问题写硬件、曲库规模和可量化数据；界面问题附分辨率、缩放和截图；在线服务问题写发生时间、网络环境、所用来源和手动查询结果。
5. **保护公开信息**：日志和附件中遮盖访问令牌、账号、无关私人路径等敏感信息，但保留错误前后的上下文。

## 备份

### 要备份哪些？

拷贝 `C:\Users\<用户名>\Documents\zerobit_config` 。

设置、曲库、歌单都在里面。
